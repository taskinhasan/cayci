# Çaycı ☕

**Sıradaki çaycı kim?** Masada çayı kimin dolduracağına karar vermek için hazırlanmış, telefonda ve bilgisayarda çalışan küçük bir çay molası oyunu.

🎮 **[Çaycı’yı oyna](https://taskinhasan.github.io/cayci/)**

## Nasıl oynanır?

1. Masadaki oyuncu sayısını **2–12** arasında belirle.
2. Her oyuncunun adını yaz. İsimler boş bırakılamaz ve birbirinden farklı olmalıdır.
3. **Çayı karıştır** düğmesine bas.
4. Demlik karıştırıp çayı bardağa doldururken sonucu bekle. Seçilen oyuncunun adı ve ona özel şakacı mesaj ekranda görünür.
5. Yeni tur için **Yeniden karıştır** düğmesine bas.

Uygulama, art arda turlarda aynı kişiyi yeniden seçmemeye çalışır.

## Proje hakkında

Çaycı, HTML, CSS ve JavaScript ile hazırlanmış tek sayfalık statik bir web uygulamasıdır. Oyuncu seçimi ve animasyonlar tarayıcıda çalışır; uygulama kullanıcı hesabı veya sunucu gerektirmez. İsimler kalıcı olarak kaydedilmez.

Arayüz mobil ekranlara uyum sağlar. İnce belli çay bardağı ve tabağı SVG ile çizilmiştir.

## Geliştirme ve yayınlama

Ana sayfa `index.html` dosyasındadır. GitHub Pages, `.github/workflows/pages.yml` iş akışıyla `main` dalındaki güncellemeleri otomatik yayımlar.

Yerelde denemek için `index.html` dosyasını bir tarayıcıda açman yeterli. Harici bir derleme adımı gerekmez.
